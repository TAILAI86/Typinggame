# ⌨️ 打字风暴 · Typing Storm

> 一个用 AI 从零写出来的**单文件网页打字游戏** —— **双击 HTML 就能玩**，无需安装、无需联网、无需任何外部资源。

中文全拼 / 首字母打字 + 英文盲打 + 代码符号练习，8 种模式、技能树成长、段位、成就图鉴、每日挑战、节奏分析。

## 🎮 在线试玩

**[▶ 打开网页直接玩 →](https://tailai86.github.io/Typinggame/)** （无需下载）

也可以克隆到本地，双击 `index.html` 即可：

```bash
git clone https://github.com/TAILAI86/Typinggame.git
# Windows
start index.html
# macOS / Linux
open index.html
```

> **零依赖**：整个游戏就是一个 HTML 文件，所有样式、脚本、词库、拼音表全部内联。
> 不联网也能玩 —— 数据只存在你自己的浏览器里。

## 🎮 玩法

屏幕中央是当前要打的**词**，下面跟着对应的**拼音**。逐字敲击键盘上的字母即可 —— 中文打的是拼音（如「图书馆」→ `tu shu guan`），英文直接打单词。

> **🔤 两种中文输入方式**：**全拼**（敲完整拼音）或**首字母**（只敲每字拼音首字母，如「你好」→ `n h`）。首页可一键切换，设置里也能改。

| 系统 | 说明 |
|---|---|
| ⚡ **极速风暴** | 60 秒限时冲刺，比拼手速与爆发力 |
| 💀 **无限生存** | 生命值有限，威胁条持续上涨 —— **每打完一个词就能把它推回一段（连击越高推得越多）**，每 25 秒词库自动升档 |
| 🎯 **精准挑战** | 一个错字整词重来，考验稳定性，零失误通关有额外加成 |
| 🏔️ **登峰造极** | 十级阶梯关卡，每关词更长更难，登顶通关 |
| 🔥 **连击狂潮** | 只追求最高连击，失误即清零，90 秒定胜负 |
| 📚 **自定义词库** | 粘贴任意文本 —— 中文自动转拼音、英文直接练，专攻课文 / 专有名词 / 考试重点 |
| 📂 **词库管理** | 可导入**多个**词库，随时练习 / 改名 / 删除，多个词库合并为一套练习序列 |
| 🩹 **错词复习** | 打错的词自动收进错词本，一键专项复习，针对性突破 |
| ⭐ **收藏夹** | 游戏中按 <kbd>Shift</kbd>+<kbd>F</kbd> 收藏喜欢的词，主动攒出专属练习集 |
| 👻 **幽灵竞速** | 刷新速度纪录后，下次游戏会回放你的最佳表现作为对手，实时显示领先 / 落后几个词 |
| 🎓 **新手引导** | 首次打开自动弹出三步图文引导，讲清玩法与输入方式；首页「玩法说明」可随时重看 |
| 🖼️ **战报分享图** | 结算后一键生成成绩卡片（速度 / 准确率 / 连击 / 段位），可下载分享 |
| ⌨️ **输入法(IME)兼容** | **自动识别系统输入法**：可直接用输入法打汉字提交，也可切英文状态敲拼音，两种都支持；检测到输入法时给出提示 |
| 📊 **各模式独立最佳** | 不同模式时长不同，速度不可横向比较 —— 统计页分模式展示各自最佳 |

### 🏆 成长与收集

- **等级 / 经验**：每局获得 XP，升级得 1 技能点
- **段位**：按最高速度划分 青铜 → 白银 → 黄金 → 铂金 → 钻石 → 大师 → 王者
- **星尘 ✦**：二级货币，来自签到与成就，用于解锁 6 款皮肤（极光 / 熔岩 / 翠竹 / 樱华 / 深海 / 鎏金）
- **成就图鉴**：44 项成就，覆盖速度、连击、累计字数、玩法、节奏与收集
- **📊 数据统计**：速度趋势折线图 + **键盘热力图**（用得多的键更亮，拖沓键标红框）+ **「拖沓键」分析** + **🖐️ 手指分工分析**（八指均衡度，指出你最爱用哪根手指、哪根手指在拖后腿）
- **🎼 打字节奏分析**：专业打字测试的核心指标 —— 不只看速度，更看**节奏是否稳定**。给出稳定性评分（0~100）、平均/中位间隔、波动幅度与击键间隔分布直方图，并给出针对性建议

### 💾 存档

- 自动保存（localStorage），3 个独立存档槽，可切换 / 复制 / 重命名
- **🗄️ 数据管理面板**：可视化存档占用（总量 + 各类数据分项体积）、导出 / 导入 JSON 文件、清理冗余、一键清空（二次确认）
- **多标签页安全**：同时开多个页面不会互相覆盖进度 —— 检测到版本冲突会自动增量合并并提示
- **存储配额兜底**：空间写满时自动分级裁剪（保留等级 / 成就 / 技能等核心进度），并在彻底失败时明确提示导出备份
- 亮色 / 暗色双主题，设置与音效可独立开关

## ✨ 细节

- **实时反馈**：逐字高亮（正确绿 / 当前亮蓝 / 错误红）、连击数字跳动、失误时屏幕震动 + 边缘红闪
- **连击热度**：连击 ≥25 变暖色，≥60 燃起火焰粒子
- **音效**：WebAudio 实时合成（无音频文件），键音随连击升高，可切换清脆 / 柔和 / 机械三种音色
- **响应式**：桌面 / 平板 / 手机自适应，无横向溢出
